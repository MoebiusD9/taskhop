# Security policy

## Supported versions

Only the latest release of Taskhop receives security fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report it privately instead: on the repository page, open the **Security**
tab and choose **Report a vulnerability**
(<https://github.com/MoebiusD9/taskhop/security/advisories/new>).

Include what you found, how to reproduce it, and what an attacker could do
with it. Taskhop is maintained by one person in their free time, so replies
are best effort, but valid reports will be fixed and credited (unless you
prefer to stay anonymous).

## Scope

In scope: the Taskhop app and its installers published on this repository's
Releases page.

Out of scope: Google's Gemini API, the operating system's keychain, and
copies of Taskhop downloaded from anywhere else. Only download Taskhop from
this repository's Releases page, and compare the file's SHA-256 checksum with
the one listed in the release.
